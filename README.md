## AI agent integration lab — November 2026

I completed a hands-on, AI-assisted Notion integration experiment using **Muse, ChatGPT, and an iPhone** as my main orchestration tools. My focus was understanding how enterprise systems connect, how to verify the work an AI agent performs, and what human approvals remain necessary.

- **Notion Public API:** Set up a workspace integration, exercised authenticated database requests, and tested access-error troubleshooting.
- **SAML SSO:** Investigated a sample HAR login failure and documented the identity-provider error and remediation.
- **Notion Custom Agent + Worker:** Orchestrated a TypeScript Worker that checks GitHub's public service status, then connected and tested it through a Notion Custom Agent.

Muse performed most of the implementation and testing; I directed the experiment, configured access, reviewed documentation, and checked progress with ChatGPT. This was a personal learning project, not a claim that I authored all the code by hand.
